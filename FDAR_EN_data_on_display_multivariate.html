Bivariate and Multivariate Graphs with Plotly Express

Author

SI Analytics

Introduction

In this lesson, we extend beyond univariate plots to explore bivariate and multivariate visualizations using Plotly in R within the RStudio environment.

These visualizations help us understand:

  • Relationships between two numeric variables
  • Distributions of numeric variables across categories
  • Relationships between categorical variables
  • Trends over time
  • Patterns involving three or more variables

Learning Objectives

By the end of this lesson, you should be able to:

  • Create scatter plots (numeric vs numeric)
  • Create grouped histograms and box/violin plots (numeric vs categorical)
  • Create stacked and percent-stacked bar charts (categorical vs categorical)
  • Create time series plots
  • Create bubble charts
  • Use faceting to compare subsets of data

Scatter Plot

plot_ly(
  mtcars,
  x = ~wt,
  y = ~mpg,
  type = "scatter",
  mode = "markers"
) %>%
  layout(
    title = "Relationship Between Weight and MPG",
    xaxis = list(title = "Weight"),
    yaxis = list(title = "Miles Per Gallon")
  )

Summary Bar Charts (Mean + SD)

summary_df <- mtcars %>%
  group_by(cyl) %>%
  summarise(
    mean_mpg = mean(mpg),
    sd_mpg = sd(mpg)
  )

plot_ly(
  summary_df,
  x = ~cyl,
  y = ~mean_mpg,
  type = "bar",
  error_y = list(array = summary_df$sd_mpg)
)

  color = ~gear,
  type = "histogram"
) %>%
  layout(barnorm = "percent")
